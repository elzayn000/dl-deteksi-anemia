# Results directory

This directory stores tabular outputs and figures generated by the experiment notebooks.

## CSV outputs

The `csv/` folder currently contains **21 CSV files**:

| Category | Files |
|---|---|
| Dataset audit | `audit_kategori_file.csv`, `file_terpakai_md5.csv` |
| Palm baselines and CNN | `baseline_palm_data_bersih.csv`, `baseline_cnn_palm_data_bersih.csv`, `varian_cnn_palm_data_bersih.csv` |
| CNN learning traces | `riwayat_pelatihan_cnn.csv`, `riwayat_varian_cnn.csv` |
| Multi-site pooling | `hasil_eksperimen_konsisten.csv` |
| Protocol replication | `replikasi_protokol_paper.csv` |
| Ablation and sensitivity | `ablasi_cv_perbandingan.csv`, `ablasi_cv_ringkasan.csv`, `ablasi_kontras_tambahan.csv`, `ablasi_mask_kosong.csv`, `ablasi_split_tunggal.csv`, `fitur_ablasi.csv` |
| Image-brightness / fairness | `fairness_cv_oof_per_kelompok.csv`, `fairness_cv_oof_selisih.csv`, `fairness_komposisi_kelompok.csv`, `fairness_kontras_berpasangan.csv`, `fairness_split_tunggal.csv` |
| Robustness | `hasil_robustness_konsisten.csv` |

## Figures

- `figures/confusion_matrix/`: eight confusion-matrix figures generated from selected experiment outputs.
- `figures/training-curves/`: baseline and modified-CNN training curves.

Reader-facing supplementary tables (S1–S3) are curated from the committed CSV outputs and indexed in [../supplementary/README.md](../supplementary/README.md). The original CSV outputs remain the source files for these tables.
