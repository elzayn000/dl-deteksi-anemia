# Results directory

This directory stores the tabular outputs and figures generated by the experiment notebooks.

## CSV outputs

The `csv/` folder contains 18 committed result files:

- Dataset audit: `audit_kategori_file.csv`, `file_terpakai_md5.csv`
- Palm baselines: `baseline_palm_data_bersih.csv`, `baseline_cnn_palm_data_bersih.csv`, `varian_cnn_palm_data_bersih.csv`
- CNN learning traces: `riwayat_pelatihan_cnn.csv`, `riwayat_varian_cnn.csv`
- Multi-site and pooling: `hasil_eksperimen_konsisten.csv`
- Protocol replication: `replikasi_protokol_paper.csv`
- Ablations: `ablasi_cv_perbandingan.csv`, `ablasi_cv_ringkasan.csv`, `ablasi_kontras_tambahan.csv`, `ablasi_mask_kosong.csv`, `ablasi_split_tunggal.csv`, `fitur_ablasi.csv`
- Fairness / image brightness: `fairness_cv_oof_per_kelompok.csv`, `fairness_cv_oof_selisih.csv`, `fairness_komposisi_kelompok.csv`, `fairness_kontras_berpasangan.csv`, `fairness_split_tunggal.csv`
- Robustness: `hasil_robustness_konsisten.csv`

Note: the list above contains 19 names because the committed directory currently includes 19 CSV files. The file inventory is authoritative.

## Figures

- `figures/confusion_matrix/`: confusion matrices generated from selected experiment outputs.
- `figures/training-curves/`: baseline and modified-CNN training curves.

Supplementary Tables S1–S3 are curated, reader-facing tables assembled from the committed CSV outputs and are indexed in [../supplementary/README.md](../supplementary/README.md).
