## Supporting notebook figures

The other two folders contain experiment-level outputs generated by the notebooks. They are retained as supporting computational artifacts and are not replacements for the final manuscript figures above.

- [`confusion_matrix/`](confusion_matrix/) — confusion-matrix plots saved from selected notebook runs.
- [`training-curves/`](training-curves/) — CNN training-history plots saved from notebook runs.

## File naming

Use the exact case-sensitive names `Figure_1.jpg` through `Figure_6.jpg` under `manuscript/`. GitHub paths are case-sensitive; names such as `figure_1.jpg` do not refer to the same file.
