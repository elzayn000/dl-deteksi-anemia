# Large and compressed CSV artifacts

This subdirectory stores detailed intermediate or audit CSV files using gzip compression (`.csv.gz`). Keeping these files compressed reduces repository size while preserving the underlying CSV data.

| File | Contents |
|---|---|
| `audit_typo_lengkap.csv.gz` | Detailed audit of filenames flagged by the typo-detection process |
| `daftar_rename_typo.csv.gz` | Original filename-rename list produced during the typo audit |
| `daftar_rename_typo_FIXED.csv.gz` | Corrected/final rename list used by the fixed cleaning workflow |
| `fitur_ablasi.csv.gz` | Feature-level ablation data generated by Notebook 23 and consumed by Notebook 25 |

## How to read

Python/pandas can read a gzip-compressed CSV directly without extracting it first:

```python
import pandas as pd

df = pd.read_csv("results/csv/large/fitur_ablasi.csv.gz")
```

To create an uncompressed copy for a workflow that expects a `.csv` filename:

```python
import gzip
import shutil

with gzip.open("results/csv/large/fitur_ablasi.csv.gz", "rb") as src:
    with open("fitur_ablasi.csv", "wb") as dst:
        shutil.copyfileobj(src, dst)
```

Do not edit the compressed files manually. If corrections are needed, regenerate the source artifacts from the corresponding notebook and replace the repository copy with the validated output.
